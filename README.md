# Yes or No Playfull

A tiny, playful question app made for fun, giggles, and dramatically avoiding the obvious answer.

## Dedicated to Ariana

Dedicated to Ariana: the most beautiful woman and the most beautiful mother out there.

Forget carving your name on a tree. At least the Internet is forever proof of my love, and this little app comes with a button that runs away when it hears "no."

## What It Does

- Asks a sweet girlfriend or marriage question.
- Lets you add someone's name to the question with a URL, such as `index.html?name=Ariana`.
- Lets you create your own custom question and button labels.
- Makes the **No** button dodge your cursor or touchscreen.
- Shows random playful messages when someone tries to say no.
- Celebrates enthusiastically when **Yes** is finally pressed.

It is not meant to be serious. It is just a cute, silly way to ask an important question and have a laugh together.

## Run It

No installation or build step is required. Open `index.html` in a web browser.

To personalize the default question with a name, add `?name=Someone` to the URL, for example `index.html?name=Ariana`.

The app is built with plain HTML, CSS, and JavaScript, so it works locally without any dependencies.

## Files

- `index.html` - The page structure and question controls.
- `style.css` - The playful pink layout and responsive styling.
- `script.js` - The presets, custom questions, messages, and runaway **No** button.
